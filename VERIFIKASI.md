# Catatan pemeriksaan

- Dua tes validasi riwayat lulus.
- Build produksi Next.js lulus.
- Lingkungan pembuatan membatasi pembacaan memori sistem. Pemeriksaan build memakai penyesuaian sementara untuk metrik memori Node.js; penyesuaian tersebut tidak masuk proyek atau ZIP.
- Uji HTTP lokal terhalang pembatasan antarmuka jaringan lingkungan. Tampilan browser dan izin mikrofon belum menjalani uji interaktif.
- Percakapan, transkripsi, dan sintesis suara langsung belum diuji karena API key pengguna belum tersedia.
- Belum ada deployment ke GitHub atau Vercel. Ikuti README untuk konfigurasi dan pengujian langsung.
